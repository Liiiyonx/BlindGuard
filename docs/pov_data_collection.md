# 第一人称 POV 数据采集与审核规范

## 目标与边界

本规范用于后续扩展第一人称道路数据。BlindGuard 当前仓库不包含真实 POV 采集流程的自动
执行器，也不会下载、抓取或生成任何真实用户画面。数据采集必须由项目负责人、采集人员和
参与者按当地法律、机构伦理要求及无障碍沟通规范共同执行。

系统仍是辅助感知工具，不是安全认证设备。训练数据覆盖提升不能替代盲杖、导盲犬、人工判断
或正式安全测试。

## 知情同意

每次采集前至少完成：

- 用参与者能够理解的方式说明目的、采集内容、保存位置、保存期限、访问人员、发布范围和
  退出方式。
- 明确获得用途授权：研究、模型训练、离线评测、内部演示应分开勾选，不能默认捆绑。
- 不使用诱导性表述，不以“必须帮助项目”为由施压；参与者可随时停止并要求删除。
- 记录 `consent_id`、授权时间、授权版本和撤回方式。身份材料与视频数据分开保存。
- 未成年人、认知障碍参与者或代理同意场景，必须遵循更严格的机构流程。

## 隐私与脱敏

优先从采集端减少隐私数据，而不是事后补救：

- 画面应聚焦前方道路，避免拍摄同行者面部、住宅门牌、车牌、手机内容和私人交谈。
- 原始数据进入受控存储；导出训练集前完成人脸、车牌、证件、屏幕和可识别住址的检查。
- 音频如无必要不采集；如确需采集，必须单独授权并去除可识别语音。
- 元数据移除 GPS、设备序列号、作者名和不必要的拍摄时间；若路线位置是研究变量，使用内部
  匿名路线编号。
- `privacy_status` 只能是 `redacted` 或 `no_personal_data`。不确定时按未通过处理。

## 采集建议

第一人称设备应固定在参与者日常使用的头部、胸前或导盲辅助装置位置，保持稳定，不要求参与者
为了拍摄改变行走姿势。每次采集前进行安全检查，采集过程由陪同人员负责环境风险。

建议覆盖：

- 设备：至少两种安装高度或镜头视场角，记录 `device_id`。
- 天气：晴天、阴天、雨天、夜间照明；记录 `weather`。
- 路线：人行道、非机动车道、路口、斑马线、公交站、施工路段；记录 `route_type`。
- 时段：早晚高峰、平峰、夜间；避免只采集畅通路段。
- 人群：拥挤、稀疏、儿童或宠物出现；不针对特定个人反复拍摄。
- 异常：遮挡、逆光、镜头污渍、抖动、雨滴，作为独立的鲁棒性切片。

## 标注与质检

- 检测框按项目统一类别表标注，至少经过一次独立复核。
- 重点检查行人、车、自行车、红绿灯、井盖、盲道和公共设施；盲道边界与被遮挡区域应保持
  一致规则。
- 模糊目标不得凭猜测补框；无法确认的红绿灯标为未知，保留为保守沉默评测样本。
- 每批数据记录标注人、复核人、版本和争议处理结果。
- 抽样回看原始视频上下文，避免只审核孤立关键帧。

## 数据划分

划分必须按路线、参与者或连续拍摄场次分组，禁止只按帧随机切分。同一段视频或同一场景的近邻帧
不能同时进入训练集和测试集，否则会产生数据泄漏。

清单中建议提供 `scene_group`。同一 `scene_group` 只能出现在一个 `split` 中。

## 伪标签策略

伪标签只能减少人工初始化成本，不能代替复核：

- 高置信伪标签仍需按批次抽查，红绿灯、井盖和盲道优先人工校正。
- 中等置信样本必须人工确认后才进入训练集。
- 低置信、模糊、域外或可能遮挡行人的样本直接丢弃，不靠堆数量补偿。
- 伪标签模型和最终学生模型都记录模型 SHA256、阈值、推理尺寸和数据版本。
- 每个新批次先建立小型人工真值验证集；未证明增益前，不直接覆盖线上模型。

## 清单格式

审核脚本读取数据根目录下的 `pov_manifest.json`：

```json
{
  "schema_version": 1,
  "records": [
    {
      "sample_id": "route-001-000123",
      "media_path": "media/route-001/000123.jpg",
      "consent_id": "consent-2026-001",
      "consent_scope": ["research", "training"],
      "privacy_status": "redacted",
      "viewpoint": "first_person",
      "split": "train",
      "scene_group": "route-001",
      "weather": "rain",
      "route_type": "sidewalk"
    }
  ]
}
```

必填字段为 `sample_id`、`media_path`、`consent_id`、`consent_scope`、
`privacy_status`、`viewpoint` 和 `split`。运行审核：

```powershell
python scripts/audit_pov_dataset.py --root data/pov --strict
python scripts/audit_pov_dataset.py --root data/pov --hash
python scripts/audit_pov_dataset.py --root data/pov --json
```

脚本只读取清单、文件路径和可选的 SHA256；它不会修改、上传或复制数据。任何错误都应先修复
清单或移除不合规样本，再用于训练或评测。
