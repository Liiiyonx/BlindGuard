# BlindGuard 模型重训练指南

> 结论先行：当前 best.pt 的三个问题（行人被误检为 car、前景手套被误检为 bicycle、
> 井盖/盲道漏检）全部指向**训练数据**，不是算法。重训一次即可解决，工作量主要在采集标注。

## 一、为什么要重训（评测证据）

见 `evaluation/metrics_report.md` 抽检结论：
1. **缺"行人"类**：模型只有 6 类，行人被硬塞进最像的 car/bicycle——行人恰是导盲最高频目标；
2. **域差距**：训练数据为横屏相机视角，部署为竖屏第一人称手机视角（手套/衣袖/盲杖入镜）；
3. **小目标细节不足**：井盖/盲道是地面小目标，imgsz=640 下竖屏构图细节大量丢失。

## 二、新类别定义（7 类）

沿用原 6 类的类别 ID 顺序（保持兼容），末尾新增 person：

```yaml
# data_blindguard_v2.yaml —— 放在项目根目录，path 指向数据集根目录
path: dataset/blindguard_v2
train: images/train
val: images/val

names:
  0: car
  1: bicycle            # 两轮非机动车（含电动自行车）
  2: manhole_cover
  3: public_facility
  4: tactile_paving
  5: traffic_light
  6: person             # 新增：行人（导盲最高频目标）
```

> 代码侧无需任何修改：config.yaml 的 risk_engine 与 class_mapping 都是按名字匹配的，
> person 已在中等风险类与中文映射里。

## 三、数据采集规范（目标 ~1800 张，1-2 天工作量）

| 类别 | 目标张数 | 采集要点 |
|---|---|---|
| person | 300+ | 各种距离/衣着/背光/背影，含拉行李、推车姿态 |
| manhole_cover | 300+ | **最难类**：不同俯角、干湿路面、阴影、圆形/方形 |
| car | 200+ | 第一人称近距视角为主（现有短板） |
| bicycle | 200+ | 明确含电动自行车；行驶+停放 |
| tactile_paving | 200+ | 条带完整段+破损段 |
| traffic_light | 150+ | 横竖构图都要 |
| public_facility | 150+ | 护栏、灯杆、配电箱等 |
| 负样本（不标注） | 100-150 | 含手套/衣袖/盲杖/纯路面——**这是压误检的关键** |

**采集方式（按优先级）**：
1. 手机直接实拍第一人称视角（与部署形态一致，不要录屏！）；
2. 让志愿者手持盲杖/戴手套入镜拍摄（覆盖 OOD 前景）；
3. 现有视频可用 `python evaluate.py bootstrap` 抽帧打底，但注意录屏失真只作补充。

**标注工具**：labelImg（YOLO 格式）或 CVAT / Roboflow。
标注规范：遮挡/截断目标照常标注可见部分；井盖框含完整边缘；盲道按连续条带整段标注；
最小目标 10px 以下不标；负样本图片零标注文件留空。

**数据划分**：train/val ≈ 8:2，同一场景的帧不要同时跨 train 和 val。

## 四、训练

```bash
# 有 NVIDIA 显卡（推荐，1500 张 960px 约 2-4 小时）
python train.py --data data_blindguard_v2.yaml --device 0

# 无显卡：用免费云端 GPU（Google Colab / Kaggle），上传数据集后同样命令
# 实在只能本机 CPU：减小规模 --imgsz 640 --epochs 80
```

## 五、验收标准（不达标不要上线）

在验证集（`evaluate.py accuracy --data data_blindguard_v2.yaml`）上：

| 类别 | AP@0.5 达标线 |
|---|---|
| person | ≥ 0.80 |
| car | ≥ 0.85 |
| manhole_cover | ≥ 0.70 |
| tactile_paving | ≥ 0.75 |
| 其余 | ≥ 0.70 |

再过一道**实拍抽检**：`python evaluate.py collect` 对新视频采样，人工抽检精确率 ≥ 0.70
（当前模型约 0.13，这是最直观的前后对比证据）。

## 六、上线与回滚

```bash
copy best.pt best_backup.pt        # 1. 备份
copy runs/detect/blindguard_v2/weights/best.pt best.pt   # 2. 替换
python smoke_test.py               # 3. 冒烟验证
python evaluate.py collect         # 4. 实拍复检
# 回滚：copy best_backup.pt best.pt
```

## 七、常见坑

- **类别 ID 顺序必须与 yaml 一致**，train.py 会按 names 解析；
- 训练曲线如果 val mAP 早停后仍上涨说明数据不够多样，补数据而非加轮数；
- 误检集中在某类（如手套→bicycle）就补该场景负样本，不要盲目调阈值；
- 上线后立刻跑一遍 `evaluate.py collect` 人工抽检留档，作为答辩的"优化前后对比"证据。
