概述

BlindGuard 是为视障人士设计的主动式导盲辅助系统，不同于 Seeing AI 等被动拍照模式。系统持续感知环境，按风险等级主动播报预警，针对中国道路定制了井盖、盲道等通用模型不识别的类别。

创新点

  • 双模型检测管线（通用 + 地面辅助）
  • HSV 纯 CV 红绿灯识别，零 API 成本
  • 编排式多角色 Agent + 确定性安全护栏
  • 离线降级 / LLM 熔断 / 模板兜底
  • IoU 跟踪目标接近/远离趋势

技术栈

  • YOLOv10s 双模型 imgsz 960
  • PyTorch + Flask
  • OpenAI 兼容 LLM
  • 浏览器 Web Speech TTS
  • Service Worker + PWA

智能体架构

本地意图路由 + LLM 角色规划 + 有界工具编排 + 确定性安全守门员。规则没认出的请求由模型做任务分解（只决定角色、不决定工具），LLM 负责理解与表达，通行授权由安全层拒绝。

10 个专业角色

  • 安全守门员 — 覆盖 LLM 输出，不授权通行
  • 实时感知员 — 读取目标、方位、灯色
  • 风险分析员 — 风险排序、优先避让
  • 无障碍导航员 — 停步/减速建议
  • 时序记忆员 — 目标接近/远离/消失
  • 视觉观察员 — 按需调用 VLM 看图
  • 偏好管家 — 语速/播报详略持久化
  • 沟通生成器 — 工具结果压缩成回复
  • 播报策略员 — 紧急度/冷却/沉默
  • 运行监控员 — 模型/工具/降级状态
